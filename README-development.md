# 한능검 공부방 — 개발/운영 메모

## 현재 구성 (가족별 난수 링크)
- 웹 UI: GitHub Pages (React + MUI + Vite)
- 비공개 자료 및 답안: Supabase Pro 조직의 별도 `cho-research` 프로젝트
- Edge Function: `khe-link-access`, 자체 256비트 난수 링크 검사, 로그인 불필요
- 버킷: `khe-exams-private` (public=false), 직접 데이터 API 접근 차단
- DB: `public.khe_link_members`(해시만 저장), `public.khe_study_records`(가족별 답안)
- CHO Trading PROD 및 Render: 변경 없음

## 사용 방법
1. 관리자만 갖고 있는 링크(`/#key=...`)로 웹앱에 접속한다. 링크는 암호와 같으므로 공개 저장소/게시물에 공유하지 않는다.
2. 가족 기출 → 가족 관리 → 별칭 입력 → 전용 링크를 발급한다.
3. 가족 기출 → 가족 관리 → 비공개 검증 ZIP 선택 → 비공개 업로드한다.
4. 각 가족은 받은 링크로 학습하고 문제별 답안을 본인 이름으로 저장한다.
5. 링크 유출 시 관리자는 해당 링크를 폐기하고 새 링크를 발급한다.

## 주의
- GitHub Pages는 공개 웹사이트지만 원본 기출문제 이미지는 웹 저장소에 게시하지 않는다.
- 현재 비공개 Storage에 업로드한 PDF/이미지는 없다. 제80회 검증 ZIP은 별도 파일로 준비돼 있으며 관리자가 1회 업로드해야 한다.
- 현재 기출 원본 73~80회 중 제80회만 50개 문항별 이미지로 분리·정답 대조됨. 나머지 회차는 검수 후 추가한다.
- 원본의 사진·도판 등 저작권을 고려하여 가정용 비공개 접근으로 운영하며, 이 방식만으로 재이용 허가가 자동 확보되는 것은 아니다.
- 현재 최종 채점·오답통계 고도화·시대 태그는 추가 구현 항목이다.
- 한능검 공식 기출 데이터와 자체 제작 5문항 체험 데이터는 혼용하지 않는다.
- Edge function에는 Supabase 서버 비밀키만 사용. 웹 소스에는 공개키만 저장.
