# 한능검 가족 공부방

## 사용 방식
1. 관리자는 **문제은행 전체 등록** 화면에서 `korean_history_rounds73-80_private.zip` 파일을 최초 1회 선택하여 비공개 Supabase Storage로 전송합니다. 이미 완료한 회차는 재업로드하지 않습니다.
2. **가족 명부**에서 별칭으로 카드를 만듭니다. 각 카드의 전용 난수 링크를 보고, 복사하거나 공유할 수 있습니다.
3. 링크를 분실하면 카드에서 **재발급**합니다. 기존 링크는 즉시 무효화하고 기존 학습기록은 유지합니다. 과거 버전에서 발급된 링크는 복원 정보가 없으므로 한 번 재발급해야 이후 조회 가능합니다.
4. 가족은 전용 링크 하나만 열면 모든 등록 문제를 **회차 선택 없이 전체 혼합 랜덤**으로 풀 수 있습니다. 아직 풀지 않은 문항을 우선합니다.
5. 시대별 학습은 검증된 시대 태그가 있는 경우에만 제공됩니다.

## 인프라
- 화면: GitHub Pages / React + MUI
- 데이터: Supabase `cho-research` 프로젝트, private Storage `khe-exams-private`
- 권한: Supabase Edge Function `khe-link-access`, 256비트 난수 링크 SHA-256 해시 검사
- 가족 링크의 서버 재조회: AES-GCM 암호문으로 보관, 서버에서 관리자에게만 복호화
- 학습기록: `public.khe_study_records`, 가족 고유 ID별 분리
- 브라우저에는 Supabase 공개키만 저장하며, Edge Function 서버 비밀키는 포함하지 않습니다.

## 실데이터 현황
- 73~80회: 총 400문항의 문항 이미지·정답·배점 ZIP 준비
- Supabase 현재 저장 상태: **80회 50문항 (이미지 50 + manifest 1)**. 나머지 350문항은 최종 업로드 전입니다.
- 회차별 원본 PDF·이미지는 공개 GitHub 저장소에 올리지 않았습니다.
- 모든 문항의 시대 태그와 전체 이미지 육안 검수는 완료되지 않았습니다.

## 운영 주의
- 가족 링크는 비밀번호와 같아 공유 범위를 제한해야 합니다.
- 관리자 링크는 가족에게 전달하지 않고, 가족 카드에서 발급한 링크만 공유합니다.
- 자료를 비공개로 보관해도 저작권자의 재이용 허가가 자동 확보되는 것은 아닙니다.
- CHO Trading 운영 DB·Render 서비스는 변경하지 않았습니다.
